# Session 05 — Deterministic policy and proposal validation

## Goal
Add fixed Northstar company policy and a read-only proposal validator so
exact, bundle, and documented-fee settlements can be accepted or rejected
with stable codes, without writing ledger rows.

## Completed changes
- `precedent.policies` owns `northstar-usd-v1`. Learned memory cannot edit it
  or raise the 5000-cent receiving-wire-fee limit. Only fee type
  `RECEIVING_WIRE_FEE` is supported.
- `precedent.ledger.validate_proposal(repo, context, proposal)` returns
  `ValidationReport`. `repo` is a `sqlite3.Connection`. Extra fields such as
  `evidence_verified=true` are `INVALID_SCHEMA` and never proof. Cited
  documents must exist and be opened in the current `RunContext`.
- Valid reports include `normalized_proposal`, empty `issues`, workspace
  `checked_ledger_revision`, `policy_id`, and cited evidence hashes. Invalid
  reports never include a commit-ready proposal. Issues are sorted by
  `ValidationCode` enum order.
- Arithmetic uses current outstanding cents, not original face amounts. A
  rejected proposal leaves balances, payment applied flags, applications,
  allocations, and `total_changes` unchanged.

T03 (`CASE-1CFA9FEE848F`, `PAY-201`, `INV-1042`, `DOC-R201`, `DOC-F201`):
opening remittance then fee notice via `read_document` validates cash 996500
/ fee 3500. The same payload without the opened notice is
`MISSING_FEE_NOTICE`. T06 cannot clear the same 3500 gap as a fee
(`OPEN_DISPUTE`). T01 exact 120000, T02 bundle 65000+35000, and T05 bundle
15000+27000+18000 validate. 1-cent and 5000-cent documented fees pass; 5001
fails `FEE_OVER_LIMIT`.

## Validation contract for Session 06
```text
validate_proposal(repo: sqlite3.Connection, context: RunContext, proposal) -> ValidationReport
```
- Revalidate inside the apply transaction; do not trust a previously displayed report.
- `STALE_LEDGER` when `context.initial_ledger_revision != workspace.ledger_revision`.
- `apply_proposal` / `get_case_snapshot` are not implemented yet.
- Policy authority is `workspace.policy` (imported `northstar-usd-v1`), not lesson text.
